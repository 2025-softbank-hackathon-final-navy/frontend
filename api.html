Serverless Router API

함수 등록 및 실행을 위한 API 명세서 v1.1

POST /function 함수 등록 (Register)

새로운 서버리스 함수를 등록하고, 실행 코드 및 환경 변수를 저장합니다.

Request Body (application/json)

Field Type Required Description
function_name String Required 함수의 식별 이름
description String Optional 함수 설명
runtime String Required 실행 환경 (예: python, node)
timeout Number Optional 실행 제한 시간(초)
function_code String Required 실행할 소스 코드 (전체 문자열)
env_vars Map Optional 환경 변수 (Key-Value)

Example Request

{
  "function_name": "my-test-func",
  "description": "API 테스트용 파이썬 함수",
  "runtime": "python",
  "timeout": 30,
  "function_code": "def handler(event, context):\n    return {\"status\": 200, \"message\": \"Hello from cURL\"}",
  "env_vars": {
    "ENV": "TEST",
    "VERSION": "1.0"
  }
}

Example Response (200 OK)

{
  "function_id": "b56ca2bb-e24d-4346-a16e-64b46325d9b3"
}
PUT /function/{function_id} 함수 수정 (Update)

기존 함수의 코드 및 설정을 업데이트합니다. (ID는 유지됨)

Path Parameters

Parameter Type Required Description
function_id String Required 수정할 함수의 UUID

Request Body (application/json)

Field Type Required Description
function_name String Required 함수 이름
description String Optional 함수 설명
timeout Number Optional 실행 제한 시간(초)
runtime String Required 실행 환경 (node, python 등)
function_code String Required 새로운 소스 코드
env_vars Map Optional 환경 변수 업데이트

Example Request

{
  "function_name": "node-data-processor-v2",
  "description": "노드 데이터 프로세서 (업데이트됨)",
  "timeout": 60,
  "runtime": "node",
  "function_code": "exports.handler = async (event) => { console.log(\"Updated version\"); return { status: \"ok\" }; };",
  "env_vars": {
    "NODE_ENV": "production",
    "MAX_RETRY": "10",
    "NEW_FEATURE": "enabled"
  }
}

Example Response (200 OK)

{
  "function_id": "96908063-6121-4ce4-88ae-ff17f2a6e5a4"
}
DELETE /function/{function_id} 함수 삭제 (Delete)

등록된 함수를 영구적으로 삭제합니다. (DB 메타데이터 및 S3 소스 코드 삭제)

Path Parameters

Parameter Type Required Description
function_id String Required 삭제할 함수의 UUID

Example Request

curl -X DELETE http://localhost:8080/function/97a4d125-2a8d-439a-8fb5-a8ba5e25db06

Example Response (204 No Content)

(No Content)
POST /function/invoke 함수 실행 (Invoke)

함수 ID를 Body에 포함하여 함수를 실행하고 결과를 동기적으로 반환받습니다.

Request Body (application/json)

Field Type Required Description
function_id String Required 실행할 함수의 UUID
args Map Optional 함수에 전달할 인자값

Example Request

{
  "function_id": "b56ca2bb-e24d-4346-a16e-64b46325d9b3",
  "args": {
    "input_value": 123,
    "test_mode": true
  }
}

Example Response (200 OK)

{
  "status": "success",
  "executionType": "warm",
  "duration": 0.112,
  "logs": "Mock Logs...",
  "result": "{\"status\": 200, \"message\": \"Hello from cURL\"}"
}
POST /function/invoke/stream 함수 스트리밍 실행 (Stream)

SSE(Server-Sent Events)를 사용하여 함수 실행 로그와 상태를 실시간으로 수신합니다.

Required Headers

Header Name Value
Content-Type application/json
Accept text/event-stream

Example Request (CURL)

curl -N -X POST http://localhost:8080/function/invoke/stream \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{
    "function_id": "b56ca2bb-e24d-4346-a16e-64b46325d9b3",
    "args": {
      "stream_mode": true
    }
  }'

Example Response (Stream)

event:connect
data:connected!

event:ping
data:

event:result
data:{"status":"success","executionType":"warm","duration":2.534,"logs":"...","result":"..."}
GET /function/stats 전체 함수 통계 조회

등록된 모든 함수의 실행 통계(호출 수, 에러율, 상태 등)를 페이징하여 조회합니다.

Query Parameters

Parameter Type Description Default
page Number 페이지 번호 (0부터 시작) 0
size Number 페이지 당 항목 수 10
sort String 정렬 기준 createdAt,desc

Example Response (200 OK)

{
  "content": [
    {
      "function_id": "b56ca2bb-e24d-4346-a16e-64b46325d9b3",
      "function_name": "my-test-func",
      "description": "API 테스트용 파이썬 함수",
      "runtime": "python",
      "timeout": 30,
      "last_executed": "2025-12-04T07:09:20.922192",
      "status": "STABLE",
      "total_requests": 15,
      "error_rate": 0.0
    }
  ],
  "pageable": { ... },
  "totalPages": 1,
  "totalElements": 1
}

GET /function/{function_id}/logs 함수 실행 로그 조회

특정 함수의 실행 이력(로그)을 페이징하여 조회합니다.

Path Parameters

Parameter Type Required Description
function_id String Required 조회할 함수의 UUID

Query Parameters

Parameter Type Description Default
page Number 페이지 번호 0
size Number 항목 수 5
sort String 정렬 기준 requestAt,desc

Example Response (200 OK)

{
  "content": [
    {
      "request_id": "884696e0-1756-40a8-9ce7-911654ea74b7",
      "duration": 0.14,
      "execution_type": "warm",
      "request_at": "2025-12-04T07:05:42.257862",
      "status": "success"
    }
  ],
  "pageable": { ... },
  "totalPages": 3,
  "totalElements": 15
}
GET /function/{function_id}/logs/{request_id} 함수 로그 상세 조회

특정 실행 요청(Request ID)의 상세 실행 로그(텍스트)를 조회합니다. (S3 저장 데이터)

Path Parameters

Parameter Type Required Description
function_id String Required 함수의 UUID
request_id String Required 조회할 실행 요청 ID (UUID)

Example Response (200 OK)

Content-Type: text/plain

[INFO] Function execution started
[INFO] Environment: production
[DEBUG] Received event: {"key": "value"}
[INFO] Processing payload...
[INFO] Calculation result: 42
[INFO] Execution completed successfully.
